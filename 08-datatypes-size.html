08 - Data Types (Part 3 of 3): Size, Range & sizeof()
🎯 What are Data Types (recap)? A data type tells the compiler what kind of value a variable stores and exactly how many bytes of RAM to reserve for it. This page is the master reference table for every basic type in C, plus the sizeof() operator that lets us verify these sizes on our own machine.
1. Complete Quick-Revision Table
Data Type Memory Size Format Range / Purpose
char 1 byte %c Compiler-dependent: usually -128 to 127 (signed) — stores 1 character
signed char 1 byte %c -128 to 127
unsigned char 1 byte %c 0 to 255 (positive only)
short int 2 bytes %hd -32,768 to 32,767 (small integers)
unsigned short int 2 bytes %hu 0 to 65,535
int / signed int 4 bytes %d -2,147,483,648 to 2,147,483,647
unsigned int 4 bytes %u 0 to 4,294,967,295
long int 4 or 8 bytes (system-dependent) %ld System-dependent — up to ±9.22 × 1018 on 8-byte systems
unsigned long int 4 or 8 bytes (system-dependent) %lu System-dependent — up to 18.4 × 1018 on 8-byte systems
long long int 8 bytes %lld -9,223,372,036,854,775,808 to 9,223,372,036,854,775,807
unsigned long long int 8 bytes %llu 0 to 18,446,744,073,709,551,615
float 4 bytes %f ~6 decimal digits precision
double 8 bytes %lf ~15 decimal digits precision
long double 16 bytes (commonly, though 10/12 bytes on some compilers) %Lf Higher precision than double
⚠ Correction / Clarification: Plain char's signedness (whether it behaves like signed char or unsigned char) is left to the compiler by the C standard — on most common compilers (including GCC on x86/Linux) it behaves as signed, so we list its range as -128 to 127. Never rely on this if a value must reliably be treated as positive-only — declare unsigned char explicitly instead.
2. Finding Size Using the sizeof() Operator
#include <stdio.h>

int main() {
  printf("char = %zu bytes\n", sizeof(char));
  printf("short int = %zu bytes\n", sizeof(short int));
  printf("int = %zu bytes\n", sizeof(int));
  printf("long int = %zu bytes\n", sizeof(long int));
  printf("long long int = %zu bytes\n", sizeof(long long int));
  printf("float = %zu bytes\n", sizeof(float));
  printf("double = %zu bytes\n", sizeof(double));
  printf("long double = %zu bytes\n", sizeof(long double));

  return 0;
}
sizeof() is a built-in compile-time operator in C — the compiler computes the answer while compiling, not while the program runs, so it costs nothing at run-time.
It returns the exact memory size of a variable or data type, in bytes, for your specific compiler and system — this is the most reliable way to check sizes rather than assuming.
Its return type is size_t, an unsigned integer type — always print it with %zu (not %d) to avoid warnings/undefined behaviour.
sizeof can be used on a type name, e.g. sizeof(int), or directly on a variable, e.g. sizeof(age) — both work.
Expected Sample Output (on a typical 64-bit system):
char = 1 bytes
short int = 2 bytes
int = 4 bytes
long int = 8 bytes
long long int = 8 bytes
float = 4 bytes
double = 8 bytes
long double = 16 bytes
⭐ The 4-Point Rule for Every Type:
Data Type → Memory Size → Range → Format Specifier
💡 Why should we care about size and range at all?
  • Picking a type too small for the data causes overflow — the value silently wraps around to an incorrect number instead of giving an error.
  • Picking a type too large wastes memory — usually harmless for a small student program, but matters a lot in large-scale software or embedded systems with limited RAM.
  • Understanding size is the foundation for later topics like pointers, arrays, and structures, where the exact byte layout of memory matters.
