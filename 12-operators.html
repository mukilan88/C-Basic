12 - Operators & Expressions in C
🎯 What are Operators? Special symbols that perform an operation on one or more values (called operands). For example in a + b, + is the operator and a, b are the operands.
1. Operators Summary

2. The Full Program
#include <stdio.h>

int main() {
  int a, b;
  printf("Enter two numbers: ");
  scanf("%d%d", &a, &b);

  // ... Arithmetic, Relational, Logical, Assignment,
  // Increment/Decrement, Conditional, Bitwise sections below

  return 0;
}
int a, b; → Declares two integer variables in a single line (comma-separated).
scanf("%d%d", &a, &b); → Reads two integers in one call. The user can separate them by a space, tab, or Enter — scanf() automatically skips whitespace between numeric inputs.
The rest of the program (shown section by section below) demonstrates every operator category using the same a and b.
3. Arithmetic Operators

Perform standard mathematical calculations.

printf("Addition (+): %d\n", a + b);
printf("Subtraction (-): %d\n", a - b);
printf("Multiplication (*): %d\n", a * b);
printf("Division (/): %d\n", a / b);
printf("Modulus (%%): %d\n", a % b);
/ (Division) → When both operands are int, C performs integer division — the decimal part is dropped, not rounded.
% (Modulus) → Gives the remainder after division. Works only with integer operands, never with float/double.
Note the double %% in the printf string — since % normally starts a format specifier, we must write it twice to print a literal % symbol.
4. Relational Operators

Compare two values and produce a Boolean-style result: C has no separate boolean type, so it uses 1 for true and 0 for false.

printf("%d > %d = %d\n", a, b, a > b);
printf("%d < %d = %d\n", a, b, a < b);
printf("%d >= %d = %d\n", a, b, a >= b);
printf("%d <= %d = %d\n", a, b, a <= b);
printf("%d == %d = %d\n", a, b, a == b);
printf("%d != %d = %d\n", a, b, a != b);
== vs = → A very common beginner bug: == compares two values for equality; a single = assigns a value. Using = inside an if condition by mistake silently changes the variable instead of comparing it.
Each result printed above is either 1 (condition is true) or 0 (condition is false).
5. Logical Operators

Combine multiple conditions into one. Also give results as 1 or 0.

printf("(a > 0 && b > 0) = %d\n", a > 0 && b > 0);
printf("(a > 0 || b > 0) = %d\n", a > 0 || b > 0);
printf("!(a > b) = %d\n", !(a > b));
&& (Logical AND) → True only if both sides are true.
|| (Logical OR) → True if at least one side is true.
! (Logical NOT) → Reverses/flips the result: true becomes false and false becomes true.
6. Assignment Operators

Shorthand ways to update a variable's value based on itself.

int c = a;

c += b; // same as c = c + b
printf("c += b: %d\n", c);

c = a; c -= b; // c = c - b
c = a; c *= b; // c = c * b
c = a; c /= b; // c = c / b
Each compound operator (+=, -=, *=, /=, and also %=) is exactly equivalent to the longer "variable = variable OP value" form, just shorter to type and slightly clearer to read once you're used to it.
Notice c is reset to a before each new example — otherwise each operation would build on the previous result.
7. Increment and Decrement Operators

Quickly add or subtract 1 from a variable. Available in two forms: prefix (++c) and postfix (c++).

c = a;
printf("c++ = %d\n", c++);
printf("After c++ = %d\n", c);

printf("++c = %d\n", ++c);

printf("c-- = %d\n", c--);
printf("After c-- = %d\n", c);

printf("--c = %d\n", --c);
Postfix c++ → Uses the current value of c in the expression first, THEN increases it by 1 afterwards.
Prefix ++c → Increases c by 1 FIRST, then uses the new value in the expression.
This ordering difference only matters when the increment is used inside a larger expression (like a printf argument); on its own line, c++; and ++c; behave identically.
The same prefix/postfix logic applies to -- (decrement).
8. Conditional (Ternary) Operator

A compact one-line replacement for a simple if-else, using the pattern condition ? value_if_true : value_if_false.

int max = (a > b) ? a : b;
printf("Maximum = %d\n", max);
It is called "ternary" because it is the only C operator that takes three operands: the condition, the true-value, and the false-value.
Equivalent longer form:
if (a > b) { max = a; } else { max = b; }
9. Bitwise Operators

Operate directly on the individual binary bits of integer values. Used heavily in embedded programming, flags/permissions, and performance-critical code.

printf("a & b = %d\n", a & b);
printf("a | b = %d\n", a | b);
printf("a ^ b = %d\n", a ^ b);
printf("a << 1 = %d\n", a << 1);
printf("a >> 1 = %d\n", a >> 1);
& (Bitwise AND) → Compares each bit; result bit is 1 only if both input bits are 1.
| (Bitwise OR) → Result bit is 1 if at least one input bit is 1.
^ (Bitwise XOR) → Result bit is 1 only if the two input bits are different.
<< (Left Shift) → Shifts all bits left by the given amount — each left-shift by 1 effectively doubles the value.
>> (Right Shift) → Shifts all bits right — each right-shift by 1 effectively halves the value (integer division by 2).
Don't confuse & (bitwise AND, works on numbers) with && (logical AND, works on true/false conditions) — mixing them up is a very common bug.
⚠ Important Practical Notes:
  • For division (a / b) and modulus (a % b), b must never be 0 — dividing by zero causes undefined behaviour / a crash.
  • Modulus % works ONLY with integer operands, never float or double.
  • Always double-check == vs = and & vs && — these are the most common operator mistakes for beginners.
