05 - Tokens (Keywords, Identifiers, Constants, Strings)
🎯 Aim: To understand what a "token" is — the smallest meaningful piece of a C program — and to learn its four core categories.
1. What is a Token?

When the compiler reads your source code, it doesn't see it as raw text — it breaks the line into the smallest individual units that still carry meaning, called tokens. Think of tokens the way words are the building blocks of a sentence: the compiler groups characters into tokens first, then figures out how those tokens combine into valid statements.

int age = 25;
This single line is broken by the compiler into 5 tokens:
int → a Keyword
age → an Identifier
= → an Operator
25 → a Constant
; → a Punctuator/Separator (marks end of statement)
2. Category 1: Keywords

Keywords are reserved words that already have a fixed, special meaning built into the C language. You cannot use a keyword as a variable name, function name, or any other identifier.

The 32 Standard C Keywords
autobreakcasechar constcontinuedefaultdo
doubleelseenumextern floatforgotoif
intlongregisterreturn shortsignedsizeofstatic
structswitchtypedefunion unsignedvoidvolatilewhile
💡 Keywords are always written in lowercase in standard C, and you have already used many of them: int, float, char, double, return, if, while, for.
3. Category 2: Identifiers

Identifiers are the names you invent for variables, functions, arrays, and so on — like age, total, calculateArea.

✅ Valid Identifier Rules
  • Can contain letters, digits, and underscore _
  • Must start with a letter or underscore, never a digit
  • Cannot be a reserved keyword
  • Case-sensitive: Age and age are two different identifiers
  • No spaces or special symbols like @, -, %
❌ Invalid Identifier Examples
  • 2age → starts with a digit
  • my-age → hyphen not allowed
  • float → it's a keyword
  • student age → contains a space
  • total$ → $ is not permitted
4. Category 3: Constants

Constants are fixed literal values that do not change — they appear directly in the code as-is (covered in full depth in Topic 10).

Constant Type Example
Integer Constant25, -10, 0
Floating-Point Constant3.14, -0.5
Character Constant'A', '9', '$'
String Constant"Hello", "Ramya"
5. Category 4: Strings

A string literal is a sequence of characters enclosed in double quotes " ", treated by the compiler as a single token — even though it may contain multiple characters. Note the distinction from a single character constant, which uses single quotes ' '.

char grade = 'A'; // character constant — single quotes
char name[] = "Ramya"; // string literal — double quotes
'A' is stored as a single byte (its ASCII numeric code).
"Ramya" is actually stored as an array of characters: R, a, m, y, a, \0 — C automatically appends a hidden \0 (null character) to mark where the string ends.
📝 One-Line Revision: A token is the smallest meaningful unit of code — Keywords (reserved words), Identifiers (your own names), Constants (fixed literal values), and Strings (quoted text) are four of the main token categories, alongside Operators and Punctuators.
