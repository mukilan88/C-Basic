15 - Formatted Input and Output (printf, scanf)
✦ Aim: To master scanf() and printf() — the two workhorse I/O functions from Topic 14 — using format specifiers to read and display every data type correctly.
1. What Does "Formatted" Mean?

printf() and scanf() are called formatted I/O functions because they use a format string containing special codes — format specifiers — that tell C exactly what data type to expect at each point: %d for int, %f for float, %lf for double, %c for char, and %s for a string. This is what lets a single function handle every data type from Topics 6–8, unlike getchar()/putchar() from Topic 14.

2. A Full Example Program
#include <stdio.h>

int main() {
  int age;
  float height;
  double salary;
  char grade;
  char name[50];

  printf("Enter your name: ");
  scanf("%s", name);
  printf("Enter your age: ");
  scanf("%d", &age);
  printf("Enter your height: ");
  scanf("%f", &height);
  printf("Enter your salary: ");
  scanf("%lf", &salary);
  printf("Enter your grade: ");
  scanf(" %c", &grade);

  printf("\n----- Student Details -----\n");
  printf("Name: %s\n", name);
  printf("Age: %d\n", age);
  printf("Height: %.2f\n", height);
  printf("Salary: %.2lf\n", salary);
  printf("Grade: %c\n", grade);

  return 0;
}
All five variables were declared following the rules from Topic 9 (Variables), each with the data type it needs from Topics 6–8.
Each scanf()/printf() pair uses the format specifier that matches its variable's exact type — mismatching them is one of the most common beginner bugs.
3. Getting Input with scanf()

We use scanf(); together with a format specifier that matches the variable's data type: %d for int, %f for float, %lf for double, %c for char, and %s for a string (character array).

⭐ Why do we use & before the variable name?
scanf() does not simply store a value into a variable — it needs to know the exact memory address where the value should be written. The & ("address-of") operator gives it that address. A string/array is a special case: the array name (name) already represents the address of its first element, so we do NOT add & before it.

Easy Rule:
  • scanf() + normal variable (int, float, double, char) → use & → e.g. &age
  • scanf() + string/character array → don't use & → e.g. name
Why is there a space before %c in scanf(" %c", &grade);?
Every time the user types a value and presses Enter, the Enter key itself leaves a leftover newline character (\n) sitting in the input buffer. If we write plain "%c", scanf() would instantly read that leftover \n instead of waiting for the user's actual character. The single leading space tells scanf() to first skip over any whitespace (spaces, tabs, newlines) before reading the real character. This trick is usually only needed for %c; %d, %f, and %lf already skip leading whitespace automatically.
4. Displaying Output with printf()

We use printf(); to send output to the screen.

How does printf() work?
• printf("hi"); → Prints a plain message exactly as written.
• printf("Age: %d\n", age); → Prints the text "Age: ", then substitutes the value stored inside age in place of %d, then moves to a new line because of \n.
What does %.2f mean?
The number between % and the specifier is the precision — it fixes how many digits appear after the decimal point. %.2f rounds the value to exactly 2 decimal digits.
Example: a stored value of 5.6789 is printed as 5.68 (rounded, not truncated).
⚠ Common Beginner Mistakes with Formatted I/O
  • Using %d to print a float or double (or vice-versa) — this reads the memory bits incorrectly and prints garbage values. The specifier must always match the variable's type.
  • Forgetting & before a normal variable in scanf() — the program may crash or silently fail to store the value, because scanf() was given a value instead of an address.
  • Using char name[50] but typing a name longer than 49 characters — this overflows the array and can corrupt nearby memory. Always size arrays generously.
  • %s with scanf() stops reading at the first space, so it cannot capture a full name with a space in it (e.g. "Ramya M"). That needs fgets() from Topic 14, not scanf("%s", ...).
