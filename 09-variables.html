C Programming

09 - Variables
✦ Aim: To understand what a variable is, how to declare and initialise one, the rules for naming them, and the idea of variable scope.
1. What is a Variable?

A variable is a named location in memory that can store a value which may change while the program runs — hence "vari-able." Every variable in C needs a data type (Topic 6) so the compiler knows how many bytes to reserve and how to interpret them, and a name (identifier) so your code can refer to it.

2. Declaration vs Initialisation
1. Declaration
Creates the variable and reserves memory, but doesn't give it a value yet.
int age;
age now exists in memory, but holds an unpredictable garbage value until something is stored in it.
2. Initialisation
Declares the variable AND gives it a starting value, in one step.
int age = 20;
This is the safer, more common style — the variable never has an unknown value.
int age; // declaration only
age = 20; // assignment — gives it a value later

int marks = 90; // declaration + initialisation together

int a = 5, b = 10, c = 15; // multiple variables, one line
Declaration and assignment can happen separately, as shown with age — first declared, then assigned a value on the next line.
Initialisation combines both into a single statement, as shown with marks — this is generally preferred since it avoids ever reading a garbage value by mistake.
C allows declaring several variables of the same type on one line, separated by commas, as shown with a, b, c.
3. Rules for Naming a Variable

A variable name is a kind of identifier (Topic 5) and must follow the same rules:

✅ Valid Variable Names
  • age, total_marks, _count, studentAge
  • Letters, digits, and underscore only
  • Must start with a letter or underscore
  • Case-sensitive: Age ≠ age
❌ Invalid Variable Names
  • 2age → starts with a digit
  • total marks → contains a space
  • float → it's a reserved keyword
  • total-marks → hyphen isn't allowed
💡 Good Naming Practice (beyond what the compiler enforces)
The compiler only cares about the rules above, but readable code also uses meaningful names. int a; compiles fine, but int studentAge; tells the next reader (including you, later) exactly what it's for — this is part of good "documentation" practice from Topic 4.
4. A Full Example
#include <stdio.h>

int main() {
  int age = 20;
  float height = 5.6;
  char grade = 'A';

  printf("Age: %d, Height: %.1f, Grade: %c\n", age, height, grade);

  age = 21; // the VALUE stored in age changes — that's what makes it a variable
  printf("Age after birthday: %d\n", age);

  return 0;
}
Output:
Age: 20, Height: 5.6, Grade: A
Age after birthday: 21

Notice age holds 20, then later holds 21 — the same named memory location, just updated with a new value.
5. A Preview of Scope (Local vs Global)

Where a variable is declared decides where it can be used — this is called its scope. This was briefly introduced in Topic 1 (Structure of a C Program) and will come up often going forward:

Type Declared Accessible From
Local Variable Inside a function (e.g. inside main()) Only within that function
Global Variable Outside every function, at the top of the file Any function in the file
📝 One-Line Revision: A variable = a named, typed memory location whose value can change; declare it with a type and a valid identifier name, and prefer initialising it immediately to avoid garbage values.
