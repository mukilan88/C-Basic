10 - Constants
🎯 Aim: To understand what a constant is, the different ways C lets us define one, and when to use each method.
1. What is a Constant?

A constant is a value that cannot be changed once the program is compiled — the opposite of a variable, whose value can change while the program runs. Constants are useful for values that are fixed by definition (like 3.14159 for π) or values you want to protect from being accidentally modified later in the code.

2. Three Ways to Define a Constant in C
1. Literal Constant
A fixed value written directly into an expression — the simplest kind, already used throughout every earlier topic.
int total = a + 10;
Here 10 is a literal integer constant.
2. const Keyword
Declares a normal, typed variable that the compiler will refuse to let you modify after initialisation.
const float PI = 3.14159;
Any later attempt like PI = 3.2; causes a compile-time error.
3. #define Preprocessor Macro
Defines a symbolic name that the preprocessor (Topic 2) textually replaces with the given value, everywhere it appears, before compilation even starts.
#define PI 3.14159

int main() {
  float area = PI * r * r;
  ...
}
Before compilation, every occurrence of PI is literally swapped for 3.14159 in the source text — PI itself has no type and is not really a "variable" at all.
3. const vs #define — Which One to Use?
Feature const #define
Processed by Compiler Preprocessor (before compilation)
Has a data type Yes (e.g. float, int) No — pure text substitution
Follows scope rules Yes (local/global like a variable) No — applies everywhere below it in the file
Uses memory Yes, like a normal variable No, it doesn't exist after preprocessing
Type-checked by compiler Yes — safer No — can cause subtle bugs
Recommended for Most modern C code (safer, debuggable) Simple global constants, especially in older-style code
💡 Modern Recommendation: Prefer const over #define when possible. Because const variables have a real type and obey scope, the compiler can catch type-mismatch mistakes that #define would silently let through (since #define is just blind text replacement, with zero type awareness).
4. Constant Types (Recap from Tokens)
Type Example Notes
Integer Constant 10, -25, 0 No decimal point
Real / Floating-Point Constant 3.14, -0.5 Has a decimal point
Character Constant 'A', '7' Single character, single quotes
String Constant "Voflic" Multiple characters, double quotes
Common beginner slip: writing #define PI 3.14159; with a trailing semicolon. Since #define is pure text replacement, that semicolon gets copied in too — turning area = PI * r * r; into area = 3.14159; * r * r;, which is a syntax error. #define lines should not end with a semicolon.
📝 One-Line Revision: A constant's value never changes — write it directly as a literal, protect a typed variable with const, or define a text macro with #define (no semicolon, no type-checking).
