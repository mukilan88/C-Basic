C Programming

03 - Interactive and Script Mode
🎯 Aim: To understand the two common ways of writing and running a C program — quick interactive/online compilation versus the traditional script (file-based) workflow — and when to use each.
1. Two Ways to Work With C

Unlike some languages (like Python) that have a true line-by-line interactive shell, C is always compiled as a whole before it runs. So "interactive mode" for C usually refers to using an online/browser-based compiler that hides the compile step from you, versus writing a real .c script file on disk and compiling it yourself in a terminal — the professional, real-world workflow.

🌐 Interactive / Online Mode
Type code directly into a website (e.g. an online C compiler/IDE), click "Run," and see output instantly — no installation, no terminal.
Good for:
  • Quick experiments, testing a single concept
  • Students without a compiler installed on their PC
  • Sharing a short snippet with someone else instantly
Limitations:
  • Not suitable for multi-file, real-world projects
  • Depends on internet access
  • Doesn't teach the real compile/run commands used on the job
💾 Script (File-Based) Mode
Write code in a text editor, save it as a .c file on your computer, then compile and run it using terminal commands (as shown in Topic 2).
Good for:
  • Real projects with multiple files
  • Learning the actual professional workflow (editor + compiler + terminal)
  • Works completely offline once the compiler is installed
Limitations:
  • Requires installing a compiler (like GCC) first
  • A few extra steps (save, compile, run) compared to clicking one "Run" button
2. The Script Mode Workflow, Step by Step
# 1. Write your code in an editor (VS Code, Notepad++, etc.)
# and save it with a .c extension
program.c

# 2. Open a terminal in the same folder and compile
gcc program.c -o program

# 3. Run the compiled executable
./program
This is exactly the three-step cycle you will repeat every single time you write and test a C program from now on: edit → compile → run.
If step 2 shows errors, you go back to step 1, fix them, and compile again — the executable from step 3 is only created if compilation succeeds cleanly.
This same cycle scales up naturally to large real-world software projects with hundreds of files — online compilers cannot realistically handle that scale.
💡 Which one should Voflic students use?
Use an online compiler when you just want to quickly test a small idea during class. But for serious practice and assignments, switch to the script mode workflow (a real code editor + GCC installed locally) as early as possible — it's what you'll use in every real job, internship, and larger project, and it forces you to get comfortable with the terminal and the actual compile commands from Topic 2.
📝 One-Line Revision: Interactive/online mode = fast, no setup, good for quick tests; Script mode = save a real .c file and compile/run it yourself in a terminal — the standard professional workflow.
