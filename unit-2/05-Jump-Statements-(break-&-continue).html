05 - Jump Statements (break & continue)
🎯 Aim: To control and alter loop execution paths dynamically using jump statements, specifically break and continue.
1. What are Jump Statements?

Normally, a loop runs predictably from start to finish. Jump statements let you override this flow: you can immediately stop and exit the entire loop (break) or bypass only the remaining statements of the current cycle and jump straight to the next pass (continue).

🛑 1. The break Statement (Emergency Exit)
Action: Terminates the loop immediately and jumps out to the code below the loop block.
for (int i = 1; i <= 5; i++) {
  if (i == 3) {
    break; // Exit loop entirely
  }
  printf("%d ", i);
}
Output: 1 2
⚡ When i == 3, the loop stops completely. Numbers 3, 4, 5 are never processed!
⏭ 2. The continue Statement (Skip Pass)
Action: Skips the rest of the current iteration and jumps directly to the update/next test.
for (int i = 1; i <= 5; i++) {
  if (i == 3) {
    continue; // Skip only 3
  }
  printf("%d ", i);
}
Output: 1 2 4 5
⚡ Only 3 is skipped! The loop continues running normally for 4 and 5.
2. Comprehensive Side-by-Side Comparison
Comparison Parameter break Statement continue Statement
Primary Function Terminates and destroys the loop completely. Skips the current cycle and begins the next iteration.
Usable Contexts Inside loops (for, while, do-while) and switch blocks. Only valid inside looping structures (not in switch).
Subsequent Iterations All future iterations are cancelled. Subsequent iterations run normally.
Real-World Analogy Pulling the emergency fire alarm to leave the building. Skipping a damaged song track to play the next song.
3. Behavior Inside Nested Loops

An essential rule for first-year exams: Jump statements affect only the innermost loop in which they reside!

for (int i = 1; i <= 2; i++) {
  for (int j = 1; j <= 3; j++) {
    if (j == 2) break; // Exits inner loop only
    printf("(%d,%d) ", i, j);
  }
}
🔍 Output & Explanation
Output: (1,1) (2,1)
Notice that break only stopped loop j. Loop i continued executing its second pass without interruption!
⚠ while Loop + continue Trap:
In a while loop, placing continue before the increment (i++) causes an infinite loop because i never updates! Always place update statements carefully.
💡 Best Practice:
Always enclose break and continue inside an if condition. Writing them unconditionally makes any statements below them unreachable dead code!
📝 One-Line Summary: break stops and exits the loop immediately; continue skips only the current pass and moves directly to the next iteration.
