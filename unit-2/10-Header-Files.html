10 - Header Files
🎯 Aim: To understand header files (.h), explore how preprocessor directives (#include, #define) function before compilation, and examine standard C libraries.
1. What is a Header File? & Preprocessor Directives

A header file (ending in .h) contains function declarations, macros, and definitions shared across programs. Lines starting with # are handled by the C Preprocessor — a tool that scans and replaces text in your source file before the actual compiler generates machine code.

📚 Angle Brackets vs Quotes
• #include <stdio.h>[cite: 1, 3]
Angle brackets tell the preprocessor to look inside the system compiler directory for standard libraries[cite: 1, 3].

• #include "myfunctions.h"
Double quotes tell it to search the current working directory first for custom, user-created header files.
⚙ Macro Definition (#define)
Used to create constant values or short shorthand functions without using memory:
#define PI 3.14159
#define SQUARE(x) ((x) * (x))
⚡ The preprocessor simply substitutes text before compilation begins.
2. Practical Code Example – Standard Math & Macros
#include <stdio.h> // For printf & scanf[cite: 1, 3]
#include <math.h> // For sqrt() & pow()

#define MAX_LIMIT 100

int main() {
  double value = 16.0;
  double root = sqrt(value); // From math.h

  printf("Square root of %.1f = %.2f\n", value, root);
  printf("Max limit defined is: %d\n", MAX_LIMIT);
  return 0;
}
💻 Output:
Square root of 16.0 = 4.00
Max limit defined is: 100
🔍 Compilation Flow:
1. Preprocessor pastes contents of stdio.h & math.h directly into your code[cite: 1, 3].
2. Replaces all instances of MAX_LIMIT with 100.
3. Hands pure C code to the compiler to generate machine instructions.
3. Most Commonly Used Standard C Header Files
Header File Full Name Key Functions Included
<stdio.h>[cite: 1, 3] Standard Input Output printf(), scanf(), getchar(), fopen()[cite: 1]
<stdlib.h> Standard General Utilities malloc(), free(), exit(), rand(), abs()
<string.h> String Manipulation strlen(), strcpy(), strcat(), strcmp()
<math.h> Mathematical Operations sqrt(), pow(), ceil(), floor(), sin()
<ctype.h> Character Type Classification toupper(), tolower(), isdigit(), isalpha()
⚠ Never Put a Semicolon on Directives:
Writing #include <stdio.h>; ❌ or #define PI 3.14; ❌ produces severe syntax errors! Preprocessor directives are text-replacement instructions, not standard C statements.
💡 Header Guard Pattern (Bonus Exam Tip):
To stop duplicate inclusions of custom headers, developers wrap them in guards:
#ifndef MYFILE_H → #define MYFILE_H → #endif
📝 One-Line Summary: Header files contain pre-built declarations; preprocessor directives (#) copy definitions and expand macros before compilation starts[cite: 1, 3].
