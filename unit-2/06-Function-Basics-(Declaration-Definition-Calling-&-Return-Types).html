🎯 Aim: To break large codebases into reusable sub-programs using functions, and master parameter passing and return types.
1. What is a Function? & Its 3 Core Pillars

A function is an independent, self-contained block of code designed to perform a specific task. Instead of writing duplicate logic multiple times, you write it once inside a function and invoke it whenever needed.

📣 1. Declaration (Prototype)
Tells the compiler the function's name, return type, and parameters before main().
int add(int, int); // ends with ;
☎ 2. Function Call
Transfers execution control from main() to the function to perform work.
result = add(10, 20);
🔧 3. Function Definition
Contains the actual body and lines of code that execute the logic.
int add(int a, int b) {
  return a + b;
}
2. Complete Practical Program
#include <stdio.h>
int calculateSum(int a, int b); // 1. Prototype

int main() {
  int sum = calculateSum(15, 25); // 2. Call
  printf("Sum = %d\n", sum);
  return 0;
}

// 3. Definition
int calculateSum(int a, int b) {
  return a + b;
}
Output: Sum = 40
Execution Path:
1. main() starts running.
2. Hits calculateSum(15, 25).
3. CPU jumps down to definition, calculates 15 + 25 = 40.
4. return 40; hands value back to sum in main().
3. The 4 Combinations of Parameters & Return Types
Category Function Header Example Description / Student Notes
No Argument, No Return void greet(void); Pure action only (e.g., printing a banner message).
With Argument, No Return void printAge(int age); Takes input data from caller, prints inside without sending a value back.
No Argument, With Return int getFixedCode(void); Generates/reads a value independently and returns it to caller.
With Argument, With Return int square(int n); Most common: Takes input data, calculates, and returns computed result.
⚠ Semicolon Alert:
Function declarations (prototypes) must end with a semicolon (int add();), but function definitions must never have one before their curly braces { }!
💡 Actual vs Formal Parameters:
• Actual Arguments: The real values passed in the call: add(15, 25).
• Formal Parameters: The receiver variables in the header: add(int a, int b).
📝 One-Line Summary: Declare first, call inside main(), and define the work in the body; return sends the computed answer back.
