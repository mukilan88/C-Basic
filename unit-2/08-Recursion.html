08 - Recursion
🎯 Aim: To understand recursion (a function calling itself), identify the critical necessity of a base condition, and trace execution stacks step-by-step.
1. What is Recursion? & Its 2 Essential Parts

Recursion is a programming technique where a function solves a problem by calling a smaller version of itself. Every recursive function must contain two parts:

🛑 1. The Base Condition (Stopping Point)
The condition that terminates further recursive calls and returns a direct, simple answer without calling the function again.
if (n == 1 || n == 0) return 1;
🔄 2. The Recursive Step (Self Call)
The statement where the function calls itself with a reduced parameter, progressing closer to the base condition.
return n * factorial(n - 1);
2. Practical Example: Factorial of a Number
#include <stdio.h>

int factorial(int n) {
  if (n <= 1) {          // 1. Base Condition
    return 1;
  } else {
    return n * factorial(n - 1); // 2. Recursive Call
  }
}

int main() {
  int n = 4;
  printf("Factorial of %d = %d\n", n, factorial(n));
  return 0;
}
💻 Output:
Factorial of 4 = 24
🧠 Math Principle:
4! = 4 × 3!
3! = 3 × 2!
2! = 2 × 1!
1! = 1 (Base condition reached!)
3. Visual Stack Flow: Winding vs Unwinding

Recursion works in two phases: Winding (calling down to the base case) and Unwinding (multiplying back up):

🔽 Step 1 (Call)
factorial(4)
waits for 4 * fact(3)
🔽 Step 2 (Call)
factorial(3)
waits for 3 * fact(2)
🔽 Step 3 (Call)
factorial(2)
waits for 2 * fact(1)
🎯 Base Hit
factorial(1)
returns 1
🔼 Unwind (Return)
2 × 1 = 2
3 × 2 = 6
4 × 6 = 24
4. Recursion vs Iteration (Loops)
Comparison Parameter Recursion Iteration (Loops)
Execution Style Function repeatedly calls itself. A set of statements repeats using a loop counter.
Stopping Mechanism Terminates when Base Condition becomes true. Terminates when Loop Condition becomes false.
Memory Overhead High (each call creates a new stack frame in memory). Low (reuses same memory addresses for loop variables).
Code Cleanliness Compact, elegant mathematical representations. Longer code structure with counter updates.
⚠ Stack Overflow Danger:
If you omit the base condition, the function calls itself infinitely until the computer runs out of stack memory, resulting in a program crash (Segmentation Fault / Stack Overflow)!
💡 Exam Memory Trick:
Always write the base condition on the very first line inside your recursive function. Treat it like the emergency brake on a train!
📝 One-Line Summary: Recursion is a function calling itself; it winds down until it hits the base condition, then unwinds back up with the final answer.
