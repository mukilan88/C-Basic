06B - The 4 Function Categories
🎯 Aim: To master the 4 core design styles of functions with clear code snippets, execution flow, and input/output behavior.
1. Visual Code Blueprint for All 4 Types
🔴 1. No Argument, No Return
🔄 Flow: Function inputs, calculates & prints internally.
void add() {
  int a = 10, b = 20;
  printf("Sum = %d\n", a + b);
}
int main() {
  add(); // main() passes nothing
  return 0;
}
Output: Sum = 30

🟢 2. With Argument, No Return
🔄 Flow: main() supplies data; function prints.
void add(int a, int b) {
  printf("Sum = %d\n", a + b);
}
int main() {
  add(10, 20); // Passes values
  return 0;
}
Output: Sum = 30

🔵 3. No Argument, With Return
🔄 Flow: Function computes internally & sends answer back.
int add() {
  int a = 10, b = 20;
  return a + b; // Sends 30 back
}
int main() {
  int res = add();
  printf("Sum = %d\n", res);
  return 0;
}
Output: Sum = 30

🟣 4. With Argument, With Return
🔄 Flow: main() gives inputs; function returns answer.
int add(int a, int b) {
  return a + b; // Computes & returns
}
int main() {
  int res = add(10, 20);
  printf("Sum = %d\n", res);
  return 0;
}
Output: Sum = 30
2. Comprehensive Comparison Table
Category Data Flow Direction Return Type Calling Syntax Real-World Analogy
No Arg, No Return Self-contained inside function void greet(); Ringing an alarm bell
With Arg, No Return main() → Function void displayAge(18); Putting coins into a vending display
No Arg, With Return Function → main() int, float, etc. code = getCode(); Rolling a dice and noting the result
With Arg, With Return Two-way (main() ↔ Function) int, float, etc. ans = square(5); Giving raw fruit to a juicer to get juice
🧠 Simple Student Rules:
• Argument: Information sent INTO the function via parentheses (...).
• Return Value: The single answer sent BACK to the caller using return.
• If nothing is returned, the return type is always written as void.
📝 Key Exam Insights & Advanced Design Rules:
• Single Return Constraint: A C function can return at most one value directly using return. To return multiple values, use pointers (Call by Reference) or structures.
• Stack Memory Lifecycle: Local variables inside functions exist on the stack frame and are destroyed immediately when return executes or the closing brace } is hit.
• Parameter Matching: Actual arguments passed in main() and formal parameters in the function definition must match in number, order, and data type.
• Reusability & Testing: Category 4 (With Arg, With Return) is preferred in software design because it decouples calculations from printing, allowing unit tests and reusability.
📝 One-Line Summary: Arguments supply input data to functions; return types specify what data the function delivers back to the caller.
