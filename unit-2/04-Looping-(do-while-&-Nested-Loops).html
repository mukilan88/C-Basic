04 - Looping (do-while & Nested Loops)
🎯 Aim: To explore exit-controlled loops using do-while, understand guaranteed single execution, and master multi-dimensional nested loops.
1. Exit-Controlled Loops: do-while

In a do-while loop, the loop statements execute first, and the condition is tested afterwards at the bottom. Because the test occurs at the end, the loop body is guaranteed to run at least once, even if the condition is False right from the beginning!

🔄 Guaranteed Single Run Example
Notice that i = 10 fails i < 5, but still prints once:
int i = 10;
do {
  printf("Value: %d\n", i);
  i++;
} while (i < 5); // Notice the semicolon!
Output: Value: 10
📋 Primary Use Case: Interactive Menus
Displaying options at least once before prompting the user:
int choice;
do {
  printf("1.Play 2.Exit -> ");
  scanf("%d", &choice);
} while (choice != 2);
⚡ Guarantees the menu shows up at least once on screen.
2. Entry-Controlled vs Exit-Controlled Comparison
Comparison Parameter while / for Loop (Entry-Controlled) do-while Loop (Exit-Controlled)
Condition Check Point Tested at the beginning (before entering body). Tested at the end (after executing body).
Minimum Executions 0 times (if condition starts as False). 1 time (guaranteed at least once).
Ending Syntax No semicolon after while(cond). Must end with semicolon: while(cond);
Best Suitable For Searching, counting, iterating arrays. Menu-driven CLI apps, re-prompting input.
3. Nested Loops (Loop Inside a Loop)

A nested loop has an outer loop and an inner loop. For every single turn of the outer loop, the inner loop completes its entire cycle from start to finish.

// Outer loop controls Rows (i)
for (int i = 1; i <= 3; i++) {
  // Inner loop controls Columns (j)
  for (int j = 1; j <= i; j++) {
    printf("* ");
  }
  printf("\n"); // Next line after inner loop
}
💻 Visualizing Rows & Columns
*
* *
* * *
Row 1 (i=1) → Inner runs 1 time → prints *
Row 2 (i=2) → Inner runs 2 times → prints * *
Row 3 (i=3) → Inner runs 3 times → prints * * *
⚠ Syntax Alert for do-while:
Forgetting the final semicolon while(cond); causes a compiler error! Unlike while and for, the do-while structure requires that closing semicolon.
💡 Nested Loop Mental Model:
Think of a clock: the outer loop is the Hour Hand, and the inner loop is the Minute Hand. The minute hand must complete 60 full ticks before the hour hand moves by just 1!
📝 One-Line Summary: do-while tests at exit and runs at least once; in nested loops, the inner loop runs completely for every single outer iteration.
