03 - Looping (while & for Loops)
🎯 Aim: To master iterative control structures, explore loop lifecycles, and build strong problem-solving skills using while and for loops.
1. Loop Lifecycle: The 4 Vital Pillars

Every loop in C depends on four core steps. If any step is missing or placed incorrectly, the loop will either produce incorrect logic or get stuck forever.

1. Initialization: Sets the start count → 2. Condition: Evaluates True/False → 3. Body: Statements to repeat → 4. Update: Modifies variable (++ / --)
🔄 1. while Loop (Condition-Driven)
Ideal when repeating code until a specific state occurs (repetition count not strictly known).
int count = 1;         // 1. Initialization
while (count <= 3) {  // 2. Condition
  printf("N=%d ", count);// 3. Loop Body
  count++;            // 4. Update
}
Output: N=1 N=2 N=3
⚡ If condition is False initially (e.g. count=5), loop body runs 0 times.
🔧 2. for Loop (Counter-Driven)
Ideal when exact count is predetermined (e.g., looping 10 or 100 times).
// for(Init ; Condition ; Update)
for (int i = 1; i <= 3; i++) {
  printf("N=%d ", i);
}
Output: N=1 N=2 N=3
⚡ Clean & compact — keeps initialization, condition, and increment together.

3. Detailed Comparison
Feature while Loop for Loop
Header Syntax Contains only the test condition while(cond). Groups init, condition, and step for(i; c; u).
Best Use Case Waiting for user input, reading files, sentinel values. Iterating through arrays, counting numbers, math tables.
Scope of Counter Variable remains active in memory after loop exits. If declared inside for(int i...), destroyed upon exit.
Evaluation Point Entry-controlled (tested before entering body). Entry-controlled (tested before entering body).
⚠ Common Traps to Avoid:
1. Infinite Loop: Forgetting count++ means condition stays True forever!
2. Accidental Semicolon: for(...); runs an empty loop and executes braces only once!
💡 Practical Coding Advice:
Choose for when you can calculate repetitions beforehand. Choose while when repetition depends entirely on conditions inside the program.
📝 One-Line Summary: while and for test conditions before entering; if the condition is False at the start, neither loop executes even once.
