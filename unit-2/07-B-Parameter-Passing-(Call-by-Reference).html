07B - Parameter Passing (Call by Reference) (USING POINTERS)
🎯 Aim: To understand how to pass memory addresses (references) to functions using pointers, enabling the function to directly modify the original variables in main().
1. What is Call by Reference?

In Call by Reference, instead of sending a copy of the value, we pass the memory address (&x) of the variable. The function receives this address inside a pointer variable (int *ptr). Any change made through the dereference operator (*ptr) directly updates the original variable in main()!

2. Complete Practical Program – Swapping Two Numbers
#include <stdio.h>

// Takes addresses of integers as pointer parameters
void swap(int *a, int *b) {
  int temp = *a; // temp gets value at address a
  *a = *b;      //place value of b into address a
  *b = temp;    // place temp into address b
}

int main() {
  int x = 10, y = 20;
  printf("Before swap: x=%d, y=%d\n", x, y);
  swap(&x, &y); // Pass memory addresses using &
  printf("After swap:  x=%d, y=%d\n", x, y);
  return 0;
}
💻 Output:
Before swap: x=10, y=20
After swap:  x=20, y=10  (Swapped!)
🔍 Why did x & y change?
swap(&x, &y) gave the function the keys to x and y's original memory cells. Writing *a = *b modified the value directly inside memory slot #2001!
3. Visual Memory Model: The Direct Key Analogy
🏠 Original Variable (x in main)
Memory Address: #2001
Value: 10 → updated to 20
The original storage box in RAM.
← Pointer Points To ←
🔑 Pointer Parameter (*a in swap)
Stored Value: #2001 (Address of x)
Operation: *a = 20;
Accesses box #2001 directly via pointer!
4. Call by Value vs Call by Reference
Comparison Parameter Call by Value Call by Reference
What is passed? Copy of the value (e.g., swap(x, y)). Memory address of the variable (e.g., swap(&x, &y)).
Parameter Declaration Normal variable: void swap(int a, int b). Pointer variable: void swap(int *a, int *b).
Original Variable Effect Original variable in main() is not affected. Original variable in main() is directly updated.
Primary Advantage Safe; protects source data from being overwritten. Can modify multiple variables and return multiple values.
⚠ Common Pointer Traps:
1. Forgetting & in function call: swap(x, y); passes values, causing type mismatch!
2. Forgetting * in function body: writing a = b; swaps memory addresses, not the actual values!
💡 Two Key Operators:
• & (Address-Of): Extracts the memory address of a variable.
• * (Dereference / Value-At): Accesses or modifies the value at that stored memory address.
📝 One-Line Summary: Call by Reference passes memory addresses using & and receives them with pointers *, allowing functions to directly modify the original variables.
