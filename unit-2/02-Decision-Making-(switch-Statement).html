UNIT 2: C PROGRAMMING

02 - Decision Making (switch Statement)
🎯 Aim: To learn multi-way branching using switch, understand the role of case, break, and default, and avoid fall-through errors.
1. What is a switch Statement?

When you need to choose one action out of many fixed choices (like selecting a menu option from 1 to 7), writing multiple else-if statements becomes messy. A switch statement tests an integer or character variable against multiple constant values called cases.

🔄 Anatomy of switch
• switch(exp): Expression must evaluate to an int or char.
• case constant: Target value with a colon (:).
• break; Jumps out of the switch block once the matching case runs.
• default: Runs if no matching case is found (like the final else).
⚠ What is Fall-Through?
If you forget to write break; at the end of a case, C will keep running into the next cases automatically — even if their values do not match!
Always end every case with break; unless you intentionally want cases to share identical logic.
2. Complete Practical Program – Day of the Week
#include <stdio.h>
int main() {
int day = 2;
 switch (day) {
  case 1:
  printf("Monday\n");
  break;
  case 2:
  printf("Tuesday\n");
  break;
  case 3:
  printf("Wednesday\n");
  break;
  default:
  printf("Invalid day number!\n");
 } 
return 0;
}
Output: Tuesday
3. switch vs else-if Ladder
Feature switch Statement else-if Ladder
Expression Checked Only single integer or character constant. Any relational or logical condition (a > 5 && b < 10).
Floating Points ❌ Not allowed (no float or double). ✅ Allowed (marks >= 75.5).
Readability Very clean for fixed menus / options. Can become messy with too many branches.
Exit Control Needs explicit break; to exit block. Exits automatically after executing matching branch.
🧠 Golden Rules of switch:
1. Case values must be constant values or literals (e.g., case 1: or case 'A':), never variables like case x:.
2. Two cases cannot have duplicate values in the same switch block.
📝 One-Line Summary: switch tests fixed integer/character values; each case needs break;, and default acts as the safety net.
