07A - Parameter Passing (Call by Value)
🎯 Aim: To understand how data is passed to functions in C using Call by Value, and why modifications to formal parameters do not affect the original variables in main().
1. What is Call by Value?

In C, functions pass arguments by value by default. This means the compiler makes a duplicate photocopy of the actual argument and places it into the formal parameter's separate memory box. Any modifications made inside the called function change only that copy, leaving the original variable completely untouched!

2. Classic Experiment: Attempting to Swap Numbers (Fails in Call by Value)
#include <stdio.h>

// Passes copies of values (Call by Value)
void swap(int a, int b) {
  int temp = a; // Swaps local copies only
  a = b;
  b = temp;
}

int main() {
  int x = 10, y = 20;
  printf("Before swap: x=%d, y=%d\n", x, y);
  swap(x, y); // Passes copies of 10 and 20
  printf("After swap:  x=%d, y=%d\n", x, y);
  return 0;
}
💻 Output:
Before swap: x=10, y=20
After swap:  x=10, y=20  (Not Swapped!)
🔍 Why did x & y remain 10 & 20?
x and y live inside main()'s memory stack frame. Parameters a and b receive only separate duplicate copies. Swapping a and b inside swap() alters only the copies, leaving x and y in main() completely untouched!
3. Visual Memory Model: The Photocopy Analogy
📄 Actual Arguments (in main)
Memory: x=#2001 (10), y=#2002 (20)
Original variables in main — untouched!
→ Copies Sent →
📄 Formal Parameters (in swap)
Memory: a=#6004 (10), b=#6005 (20)
Swapped inside function, then destroyed on exit.
4. Actual Arguments vs Formal Parameters
Comparison Parameter Actual Arguments Formal Parameters
Where are they defined? Inside the function call statement in main(). In the function declaration / header line.
Format Can be variables, expressions, or constants: swap(x, y) or swap(10, 20). Must be explicit variable declarations: void swap(int a, int b).
Memory Allocation Allocated when main() begins execution. Created when the function is called; destroyed immediately upon return.
⚠ The Swapping Trap:
Writing a simple swap function like swap(int a, int b) using Call by Value will not swap the original variables in main()! (Swapping originals requires pointers / Call by Reference).
💡 Why use Call by Value?
Safety & Independence: It ensures functions cannot accidentally corrupt or overwrite important data inside caller functions like main().
📝 One-Line Summary: Call by Value passes only a duplicate copy of the data; changes inside the called function never affect original variables in main().
