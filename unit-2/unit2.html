UNIT 2: C PROGRAMMING

01 - Decision Making (if & if-else)
🎯 Aim: To learn how programs make decisions and execute specific blocks of code based on conditions being True or False.
1. What is Decision Making?

In C, decision-making statements control the execution flow. A condition is evaluated: if it is True (non-zero), the designated code executes; if False (0), that code is skipped.

👉 1. Simple if Statement
Executes the block only when the condition is True.
int marks = 65;
if (marks >= 50) {
  printf("Passed!\n");
}
Flow:
Condition is True → Prints "Passed!"
Condition is False → Ignores the block and moves on.
⚖ 2. if-else Statement
Provides two clear paths: one for True, one for False.
int age = 16;
if (age >= 18) {
  printf("Eligible to vote\n");
} else {
  printf("Not eligible\n");
}
Output: Not eligible
2. Practical Example: Check Even or Odd
#include <stdio.h>
int main() {
  int num = 7;
  if (num % 2 == 0) {
    printf("%d is Even\n", num);
  } else {
    printf("%d is Odd\n", num);
  }
  return 0;
}
3. Quick Syntax Guide
Statement Type When to Use? Syntax Form
Simple if When there is only one optional action. if (condition) { ... }
if - else When there are two mutually exclusive actions. if (...) { ... } else { ... }
else-if Ladder When there are 3 or more distinct conditions to test. if (...) { } else if (...) { } else { }
⚠ Common Beginner Mistake:
Do not put a semicolon right after the if condition: if (a > b); ❌
A semicolon terminates the statement immediately, causing the block below to run unconditionally!
📝 One-Line Revision: if runs code when a condition is True; else runs code when that condition is False.
