09 - Scope and Lifetime of Variables
🎯 Aim: To understand variable visibility (Scope), how long variables survive in memory (Lifetime), and how storage classes define their behavior.
1. Scope vs. Lifetime – Fundamental Concepts
👁 Scope (Visibility / Where?)
The specific region of code where a variable can be seen, read, or modified (e.g., inside one function vs. the entire file).
⏳ Lifetime (Duration / How Long?)
The period of time during program execution that a variable stays allocated in RAM before being destroyed.
2. Local vs. Global Variables – Code Example
#include <stdio.h>

int global_var = 100; // Global Scope (accessible anywhere)

void demoFunction() {
  int local_var = 10;  // Local to demoFunction only
  printf("Inside: local=%d, global=%d\n", local_var, global_var);
}

int main() {
  demoFunction();
  // printf("%d", local_var); // ERROR! local_var is dead here
  printf("Main: global=%d\n", global_var);
  return 0;
}
💻 Output:
Inside: local=10, global=100
Main: global=100
🔍 What Happened?
• local_var was born when demoFunction() was called and destroyed when it returned.
• global_var remained alive across the whole program.
3. Summary Table: Local vs. Global Variables
Feature Local Variable Global Variable
Where Declared? Inside a function or block { }. Outside all functions (top of the file).
Scope (Visibility) Visible only inside its enclosing { }. Visible throughout all functions in the program.
Lifetime (Memory) Created on function entry, destroyed on return. Stays in memory from program start to end.
Default Initial Value Garbage value (random junk numbers). Zero (0) automatically initialized.
4. The 4 Storage Classes in C
Keyword Storage Location Default Value Scope Lifetime
auto Stack RAM Garbage Local block Function execution only (default for locals)
static Data Segment Zero (0) Local block Entire program duration (retains value!)
register CPU Register Garbage Local block Fastest access (no & address operator)
extern Data Segment Zero (0) Global Shares global variables across multiple files
⭐ The static Superpower:
A static int count = 0; inside a function does not reset when the function finishes. It retains its modified value for subsequent function calls!
⚠ Exam Warning:
Avoid unnecessary global variables! Any function can alter them, making debugging large programs difficult. Always prefer local variables when possible.
📝 One-Line Summary: Scope determines where a variable is accessible; Lifetime determines how long it exists in RAM.
