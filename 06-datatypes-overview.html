06 - Data Types (Part 1 of 3): Overview & Basic Types
✦ Aim: To understand what a data type is and to learn the five basic data types every C program is built from.
1. What is a Data Type?

Every variable in C must be given a data type before it can be used. The data type tells the compiler two things: (1) how many bytes of memory to reserve for the variable, and (2) what kind of value it is allowed to hold (a whole number, a decimal number, a single letter, etc.). Without a data type, the compiler would not know how to interpret the bits stored in memory.

Data Type Used for Example Value
int Whole numbers (no decimal point) 20, -5, 1000
float Decimal numbers, ~6 digits of accuracy 5.5, 3.14
double Decimal numbers needing more accuracy 25000.75
char A single character 'A', '9', '$'
char name[50] A group of characters (a word/string) "Ramya"
💡 Why do we have both float and double?
Both store decimal numbers, but double reserves twice the memory (8 bytes vs 4 bytes) and can store a decimal value far more precisely (about 15 digits vs about 6 digits). Use double whenever accuracy matters, such as for money (salary) or scientific calculations.
2. The Two Broad Families of Data Types
🔢 Integer Family
Store whole numbers only — no decimal point, ever.
int, short int, long int, long long int, and their unsigned versions. Every one of these has multiple "flavours" for controlling size and sign — covered in full in Part 2 of this topic.
🔢 Floating-Point Family
Store numbers that may include a decimal point.
float, double, and long double — differing only in how much memory (and therefore how much precision) each reserves.
What about char?
char technically belongs to the integer family too — internally, a character is just stored as a small integer (its ASCII code, e.g. 'A' is stored as 65). C simply lets us treat that number as a printable character using the %c format specifier.
