🎯 Aim: To group logically related variables of different data types under a single user-defined record using struct, access members using the dot (.) operator, read runtime input, and analyze physical memory allocation.
1. What is a Structure? & Array vs. Structure

While an Array holds multiple items of the same data type (homogeneous), a Structure (defined by keyword struct) allows bundling multiple variables of different data types (heterogeneous) into one named blueprint.
Syntax: struct TemplateName { member1; member2; ... }; → Always ends with a semicolon ;!

👁 Memory Layout for one variable struct Student s1; (Each member gets its own independent memory):
101
s1.rollNo
int (4 Bytes)
"Mukilan"
s1.name
char[20] (20 Bytes)
92.50
s1.marks
float (4 Bytes)
⚡ Total Size ≈ sizeof(rollNo) + sizeof(name) + sizeof(marks) = 28 Bytes (plus optional padding bytes for CPU alignment).
2. Complete Runtime Input & Display Program
#include <stdio.h>

// 1. Blueprint declaration (no memory allocated yet)
struct Student {
    int rollNo;
    char name[20];
    float marks;
}; // Semicolon is mandatory!

int main() {
    // 2. Variable creation (RAM allocated here)
    struct Student s1;

    printf("Enter Roll Number: ");
    scanf("%d", &s1.rollNo);

    printf("Enter Name: ");
    scanf("%s", s1.name); // Array name is address

    printf("Enter Marks: ");
    scanf("%f", &s1.marks);

    // 3. Printing details using Dot (.) Operator
    printf("\n--- Student Record ---\n");
    printf("Roll No : %d\n", s1.rollNo);
    printf("Name : %s\n", s1.name);
    printf("Marks : %.2f\n", s1.marks);

    return 0;
}
💻 Terminal Execution (Runtime):
Enter Roll Number: 101
Enter Name: Mukilan
Enter Marks: 92.5

--- Student Record ---
Roll No : 101
Name : Mukilan
Marks : 92.50
🔍 The Member Access Operator (.)
• Known as the Dot Operator or Period Operator.
• Syntax: variable_name.member_name
• Directs the compiler to the relative memory offset of that exact field within the structure variable.
3. Array vs. Structure Comparison
Property Array Structure
Data Types Homogeneous (all elements must be identical type) Heterogeneous (members can be mixed: int, float, char)
Access Method Accessed by numeric subscript index: arr[0] Accessed by named identifier via dot operator: s1.name
Memory Allocation Contiguous blocks of identical element size Contiguous sequence of individual member types (+ padding)
Keywords No special keyword needed (e.g., int a[10];) Uses struct keyword (e.g., struct Book b;)
⚠ Semicolon Alert After Definition:
Forgetting the closing semicolon }; after the structure definition is one of the most frequent beginner syntax errors in C! The compiler will flag errors on the lines that follow.
💡 Using typedef for Cleaner Syntax:
Typing struct Student s1; every time is lengthy. You can simplify it with typedef:
typedef struct { int id; } Student; → Now you can declare variables simply as Student s1;!
📝 One-Line Summary: Structures bundle diverse data types into a single named record; individual members are accessed using the Dot (.) operator and stored sequentially in memory.
