🎯 Aim: To break the fixed-size limitations of standard arrays by allocating, resizing, and freeing heap memory at runtime using malloc(), calloc(), realloc(), and free().
1. Static vs. Dynamic Allocation (Stack vs. Heap)
📦 Static / Stack Memory:
• Fixed size decided at compile time (e.g., int a[100];).
• Cannot grow if more users enter; wastes space if empty.
• Automatically cleared when function ends.
🏗 Dynamic / Heap Memory:
• Exact size requested at runtime from OS using pointers.
• Persists until explicitly released using free().
• Managed manually by programmer via <stdlib.h>.
2. The 4 Core DMA Functions
1. malloc()
Memory Allocation: Allocates a single raw block of specified bytes.
ptr = (int*) malloc(n * sizeof(int));

Leaves memory with garbage values.
2. calloc()
Contiguous Allocation: Takes 2 arguments: number of items & size per item.
ptr = (int*) calloc(n, sizeof(int));

Initializes all allocated bytes to Zero (0)!
3. realloc()
Re-allocation: Expands or shrinks an already allocated heap block.
ptr = realloc(ptr, new_size);

Preserves original data during resizing.
4. free()
De-allocation: Returns the allocated heap memory back to the Operating System.
free(ptr); ptr = NULL;

Prevents dangerous Memory Leaks.
3. Complete Runtime Demonstration (Allocate, Input, Resize & Free)
#include <stdio.h>
#include <stdlib.h> // Required for DMA

int main() {
    int n = 3, *ptr, sum = 0;

    // 1. Allocate heap space for 3 integers
    ptr = (int*) malloc(n * sizeof(int));

    // Always check if memory allocation succeeded
    if (ptr == NULL) {
        printf("Memory Allocation Failed!\n");
        return 1;
    }

    printf("Enter %d elements:\n", n);
    for (int i = 0; i < n; i++) {
        scanf("%d", &ptr[i]);
        sum += ptr[i];
    }
    printf("Initial Sum = %d\n", sum);

    // 2. Expand array to 4 elements at runtime
    ptr = (int*) realloc(ptr, 4 * sizeof(int));
    printf("Enter 1 extra element: ");
    scanf("%d", &ptr[3]);
    sum += ptr[3];
    printf("Updated Total Sum = %d\n", sum);

    // 3. Free memory to prevent memory leak
    free(ptr);
    ptr = NULL;
    return 0;
}
💻 Terminal Execution (Runtime):
Enter 3 elements:
10 20 30
Initial Sum = 60

Enter 1 extra element: 40
Updated Total Sum = 100
🔍 Why Typecast (int*)?
Functions like malloc() return a generic pointer (void*) because they only allocate raw bytes without knowing what data type you want to store.
Prefixing with (int*) typecasts the memory chunk into an integer array pointer!
4. malloc() vs. calloc() Comparison
Feature malloc() calloc()
Syntax void* malloc(size_t total_bytes); void* calloc(size_t num_elements, size_t element_size);
Parameters 1 argument (total byte calculation) 2 arguments (number of items, size of each item)
Initial Values Contains random garbage values Initializes every single allocated byte to Zero (0)
Speed Faster (does not spend CPU cycles clearing bytes) Slightly slower (clears all bytes to 0)
⚠ Memory Leak & Dangling Pointer:
• Memory Leak: Forgetting to call free(ptr) consumes RAM permanently until program quits.
• Dangling Pointer: Accessing ptr after calling free(ptr) causes crashes! Always write ptr = NULL; immediately after freeing.
💡 Always Check for NULL:
If the computer runs out of RAM, malloc() returns NULL. Always verify if (ptr == NULL) before accessing array indices to prevent Segmentation Faults!
📝 One-Line Summary: malloc() allocates uninitialized bytes, calloc() allocates zeroed memory, realloc() resizes existing heap blocks, and free() releases memory back to the OS.
