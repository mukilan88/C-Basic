1. What is a Union? & Shared Memory Architecture

A Union is a user-defined data type similar to a structure, with one fundamental difference: all members share the exact same memory space. While a struct allocates memory for every member, a union's total size equals only the size of its largest member.
Syntax: union TemplateName { member1; member2; ... }; → Only one member can hold a meaningful value at any given time!

📦 struct Data (Independent Locations)
i (4B)
f (4B)
ch (1B)
Total = 4 + 4 + 1 = 9+ Bytes (Each has its own address)
🔄 union Data (One Shared Location)
[ Shared 4 Bytes ] ← i / f / ch
Total = max(4, 4, 1) = 4 Bytes (All start at the exact same address!)
2. Complete Runtime Input & Overwrite Demonstration
#include <stdio.h>

union Record {
    int id;
    float salary;
    char grade;
};

int main() {
    union Record r;

    // 1. Correct Usage: Use one member at a time
    printf("Enter ID: ");
    scanf("%d", &r.id);
    printf("Stored ID = %d\n", r.id);

    printf("Enter Salary: ");
    scanf("%f", &r.salary); // Overwrites id!
    printf("Stored Salary = %.2f\n", r.salary);

    // 2. Observing Overwrite / Corruption
    printf("\n--- Inspecting Overwritten id ---\n");
    printf("id value now: %d (Corrupted!)\n", r.id);
    printf("Size of union: %lu bytes\n", sizeof(r));

    return 0;
}
💻 Terminal Execution (Runtime):
Enter ID: 101
Stored ID = 101

Enter Salary: 45000.50
Stored Salary = 45000.50

--- Inspecting Overwritten id ---
id value now: 1194270848
Size of union: 4 bytes
🔍 Why Did ID Turn Into Garbage?
Because id and salary share the exact same 4 bytes in RAM! Writing 45000.50 stores IEEE-754 floating-point bits across those 4 bytes, wiping out the integer bits that represented 101.
3. Detailed Comparison: Structure vs. Union
Feature Structure (struct) Union (union)
Keyword struct union
Memory Allocation Sum of all member sizes (+ padding bytes) Equal to the size of the largest member only
Member Sharing Each member has its own distinct address All members share the single starting address
Value Retention All members hold valid values simultaneously Only one member holds a valid value at a time
Primary Use Case Modeling real entities (Student, Employee, Point) Hardware registers, memory conservation, variants
⚠ The Overwrite Trap:
Never write to member B and expect member A to retain its old data. Assigning a value to any member directly overwrites the bytes shared by all other members in that union!
💡 Real-World Use Case for Union:
Unions shine when designing a system where an item can be identified by either a Passport Number (string) or an Aadhaar Number (integer) — never both at once — saving precious RAM on embedded microcontrollers!
📝 One-Line Summary: A Union allocates only enough memory for its largest member; all members share that single address space, so modifying one member overwrites the rest.
