🎯 Aim: To master standard C library string manipulation functions — strlen(), strcpy(), strcat(), and strcmp() — and observe their operations at runtime.
1. The 4 Essential String Functions in C

Since C cannot directly assign or concatenate strings using operators like = or +, the standard header <string.h> provides pre-built functions to perform these common operations.

📏 1. strlen(str) – String Length
Counts all characters until it hits '\0'.
Note: The null terminator is never counted!
📋 2. strcpy(dest, src) – String Copy
Copies text from src into dest.
Rule: dest must have enough space!
🔗 3. strcat(dest, src) – Concatenate
Attaches src to the end of dest.
Overwrites dest's old '\0' with src.
⚖ 4. strcmp(str1, str2) – Compare
Compares ASCII character by character.
Returns 0 if both strings match identically!
2. Comprehensive Practical Program (Runtime Demonstration)
#include <stdio.h>
#include <string.h>

int main() {
    char str1[50], str2[50], copyStr[50];

    printf("Enter first string: ");
    scanf("%s", str1);
    printf("Enter second string: ");
    scanf("%s", str2);

    // 1. Length of string
    printf("\nLength of str1 = %lu\n", strlen(str1));

    // 2. Copying string
    strcpy(copyStr, str1);
    printf("Copied string = %s\n", copyStr);

    // 3. String Comparison
    if (strcmp(str1, str2) == 0) {
        printf("Comparison = Strings are EQUAL\n");
    } else {
        printf("Comparison = Strings are DIFFERENT\n");
    }

    // 4. Concatenation (joining)
    strcat(str1, str2);
    printf("Concatenated = %s\n", str1);

    return 0;
}
💻 Terminal Execution (Runtime):
Enter first string: Hello
Enter second string: World

Results:
Length of str1 = 5
Copied string = Hello
Comparison = Strings are DIFFERENT
Concatenated = HelloWorld
🧠 How strcmp() Evaluates Values
• strcmp(s1, s2) == 0 → Exact match.
• strcmp(s1, s2) > 0 → First differing character in s1 has larger ASCII value.
• strcmp(s1, s2) < 0 → First differing character in s1 has smaller ASCII value.
3. Quick Reference Matrix for <string.h>
Function Prototype Destination Buffer Requirement Return Value Common Mistake to Avoid
size_t strlen(const char *s) Read-only (doesn't modify) Number of characters before '\0' Confusing strlen() with sizeof()
char *strcpy(char *dest, char *src) Must hold at least strlen(src) + 1 Pointer to dest Reversing args: strcpy(src, dest) ❌
char *strcat(char *dest, char *src) Must hold strlen(dest) + strlen(src) + 1 Pointer to dest Target array too small (Buffer Overflow)
int strcmp(char *s1, char *s2) Read-only (neither is modified) 0, positive integer, or negative integer Using s1 == s2 (which only compares RAM addresses!)
⚠ The "s1 == s2" Exam Trap:
Writing if (str1 == str2) in C checks if both strings live at the exact same memory address, NOT if their text contents match! Always use strcmp(str1, str2) == 0 to test textual equality.
💡 strlen() vs sizeof():
For char s[10] = "Hi";:
• strlen(s) returns 2 (counts letters up to '\0').
• sizeof(s) returns 10 (total allocated bytes in RAM).
📝 One-Line Summary: Include <string.h> to use strlen (length), strcpy (copy), strcat (append), and strcmp (compare content).
