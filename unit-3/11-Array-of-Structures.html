1. Concept & Memory Layout of an Array of Structures

A single structure variable stores details of only one entity. To store records for a whole class of 60 students or 100 employees, we create an Array of Structures.
Syntax: struct StructureName array_name[size]; → e.g., struct Student s[3]; reserves memory for 3 contiguous student records in RAM.

👁 Contiguous Storage of struct Student s[3] (Each block = 1 complete record):
s[0] (Record 1)
.id = 101
.name = "Arun"
.marks = 85.0
Address: #2000
s[1] (Record 2)
.id = 102
.name = "Bala"
.marks = 92.5
Address: #2028
s[2] (Record 3)
.id = 103
.name = "Charan"
.marks = 78.0
Address: #2056
⚡ Total Size = 3 × sizeof(struct Student). In RAM, s[1] begins immediately after s[0] finishes!
2. Runtime Input & Display Program (Loop Traversal)
#include <stdio.h>

struct Student {
    int id;
    char name[20];
    float marks;
};

int main() {
    struct Student s[2]; // Array of 2 records

    // 1. Reading input for multiple records
    for (int i = 0; i < 2; i++) {
        printf("Enter ID, Name, Marks for Student %d:\n", i + 1);
        scanf("%d %s %f", &s[i].id, s[i].name, &s[i].marks);
    }

    // 2. Displaying all student records
    printf("\n--- Student Database ---\n");
    for (int i = 0; i < 2; i++) {
        printf("[%d] ID: %d | Name: %s | Marks: %.2f\n",
               i + 1, s[i].id, s[i].name, s[i].marks);
    }
    return 0;
}

🔍 Syntax Anatomy: s[i].member
• s[i]: Selects the whole structure instance at array index i.
• .member: Accesses the specific variable field inside that indexed structure.
• Notice: &s[i].id passes the memory address of the integer field inside the i-th record.
3. Common Array of Structures Operations
Operation Purpose Code Logic Pattern
Linear Search Find a record by specific ID or Name if (s[i].id == searchId) { printf("Found: %s", s[i].name); }
Find Topper / Max Scan all records to find highest mark if (s[i].marks > max) { max = s[i].marks; topperIdx = i; }
Class Average Sum a specific numeric member across all records total += s[i].marks; → avg = total / n;
Sorting Sort records based on a member field Swap complete structure: struct Student temp = s[i]; s[i] = s[j]; s[j] = temp;
⚠ Subscript vs Dot Precedence Trap:
Always write s[i].id and NOT s.id[i]!
• s[i].id: The id field of the i-th student.
• s.id[i]: Treats id itself as an array, which causes a syntax error!
💡 Direct Assignment Feature:
In C, you can copy an entire structure record to another in one single line: s[0] = s[1];! C automatically copies every individual field (including internal string arrays) byte-by-byte.
📝 One-Line Summary: An Array of Structures stores multiple composite records side-by-side in RAM; access individual fields using array_name[i].member inside standard loops.
