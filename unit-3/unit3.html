1. What is an Array? & Memory Allocation

An array is a collection of multiple variables of the same data type stored sequentially in contiguous (side-by-side) memory locations under a single common name.
Syntax: data_type array_name[size]; → e.g., int a[5]; reserves 5 continuous integer blocks (5 × 4 bytes = 20 bytes in RAM).

2. Runtime Input & Display Program (Step-by-Step)
#include <stdio.h>
int main() {
  int n;
  printf("Enter number of elements: ");
  scanf("%d", &n);

  int a[n];
  // 1. Reading values at Runtime
  printf("Enter %d numbers:\n", n);
  for (int i = 0; i < n; i++) {
    scanf("%d", &a[i]); // & passes memory address
  }

  // 2. Printing elements along with their indices
  printf("\nStored Array Elements:\n");
  for (int i = 0; i < n; i++) {
    printf("Element at index [%d] = %d\n", i, a[i]);
  }
  return 0;
}

🔍 How Runtime Input Works
• When i = 0, scanf("%d", &a[0]) stores 12 directly in address #2000.
• When i = 1, scanf("%d", &a[1]) stores 25 in address #2004, and so on.
3. Common Array Operations
Operation What it does? How to write the loop code?
1. Traversal Visiting each element once (e.g., to print or count). for(int i = 0; i < n; i++) { printf("%d ", a[i]); }
2. Sum & Average Accumulating all values to compute totals. sum += a[i]; → float avg = (float)sum / n;
3. Search (Linear) Checking if a specific target value exists in the array. if (a[i] == key) { printf("Found at index %d", i); break; }
4. Maximum / Minimum Comparing each element to find highest or lowest. if (a[i] > max) { max = a[i]; } (Initialize max = a[0])
⚠ Out of Bounds Danger (No Bounds Checking):
In C, if size is 5, accessing a[5] or a[10] is illegal! C won't show an error at compile time, but it reads/overwrites random RAM data (producing garbage values or program crashes)!
💡 Why Arrays Start at 0:
Index i actually acts as an offset formula:
Address = Base_Address + (Index × Size_of_Data)
For index 0: #2000 + (0 × 4) = #2000 (Exact start point with zero shift!).
📝 One-Line Summary: 1D Arrays store multiple same-type items side-by-side in RAM; indices run from 0 to n-1, accessed using a[i].
