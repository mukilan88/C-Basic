1. What is a String in C? & Memory Layout

In C, there is no separate string keyword like in Java or Python. A string is simply a 1D array of characters that ends with a special sentinel value called the Null Terminator ('\0').
The null character has an ASCII value of 0 and signals the end of the text to functions like printf().

☝ Rule of Thumb: An N-character word always needs an array size of at least (N + 1) to store the terminating '\0'!
2. Runtime Input & Display Program
#include <stdio.h>

int main() {
    char firstName[30];
    char fullName[50];

    // 1. Reading single word (stops at space)
    printf("Enter first name: ");
    scanf("%s", firstName); // No & needed!

    // Clear newline buffer before reading multi-word string
    getchar();

    // 2. Reading complete line with spaces safely
    printf("Enter full name: ");
    fgets(fullName, sizeof(fullName), stdin);

    // 3. Printing strings
    printf("\n--- Profile ---\n");
    printf("First Name: %s\n", firstName);
    printf("Full Name : %s", fullName);

    return 0;
}
💻 Terminal Execution (Runtime):
Enter first name: Mukilan
Enter full name: Mukilan Selvaraj

--- Profile ---
First Name: Mukilan
Full Name : Mukilan Selvaraj
🔍 Why No & in scanf("%s", str)?
In C, the array name by itself (firstName) already represents the base memory address of the array (&firstName[0]). Adding an & is redundant.
3. Input Methods Comparison
Input Function Handles Spaces? Buffer Overflow Safety Best Use Case
scanf("%s", str); ❌ No (stops reading at space/tab/newline) Unsafe (can overflow if input is too long) Single words (names, codes, IDs)
fgets(str, n, stdin); ✅ Yes (reads until enter key is pressed) ✅ Safe (reads at most n - 1 characters) Full sentences, addresses, full names
gets(str); ✅ Yes ❌ Removed from modern C (dangerous!) Never use in modern programming
⚠ Forgetting the Null Character:
If you assign characters manually: char s[3] = {'H','i'}; without adding '\0', printf("%s", s) keeps reading past the array until it randomly finds a 0 in memory, printing strange junk characters!
💡 Single Quotes vs Double Quotes:
• 'A' → Single character constant (1 byte).
• "A" → String literal containing two bytes: 'A' and '\0'!
📝 One-Line Summary: Strings are 1D character arrays terminated by '\0'; use scanf("%s") for single words and fgets() for lines containing spaces.
