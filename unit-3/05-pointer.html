1. What is a Pointer? & Physical Memory View

A pointer is a special variable that stores the memory address of another variable instead of a regular data value.
Syntax: data_type *pointer_name; → e.g., int *ptr = &num; tells the compiler that ptr holds the address of integer num.

🔑 Pointer Variable (ptr)
#2004
Lives at Address: #5000
points to (&num) → *ptr fetches value
📦 Target Variable (num)
25
Lives at Address: #2004
📍 1. Address-Of Operator (&)
Extracts the unique RAM address where a variable is located.
&num → Gives #2004 (Printed with format specifier %p).
🔎 2. Dereference Operator (*)
Goes to the address stored in the pointer and extracts or modifies the data inside.
*ptr → Reads or overwrites value 25.
2. Runtime Input & Pointer Manipulation Program
#include <stdio.h>

int main() {
    int num;
    int *ptr = &num; // ptr stores the address of num

    printf("Enter a number: ");
    scanf("%d", &num); // Reading runtime input

    printf("\n--- Inspecting Values ---\n");
    printf("Direct Value (num) = %d\n", num);
    printf("Address of num (&num) = %p\n", &num);
    printf("Stored in ptr (ptr) = %p\n", ptr);
    printf("Value via pointer (*ptr) = %d\n", *ptr);

    // Modifying original variable through pointer
    *ptr = *ptr + 10; // num is updated directly in RAM
    printf("\nAfter *ptr += 10, num = %d\n", num);

    return 0;
}
💻 Terminal Execution (Runtime):
Enter a number: 25

--- Inspecting Values ---
Direct Value (num) = 25
Address of num (&num) = 0x7ffd2004
Stored in ptr (ptr) = 0x7ffd2004
Value via pointer (*ptr) = 25

After *ptr += 10, num = 35
🔍 What Just Happened?
• ptr holds 0x7ffd2004 (the RAM address of num).
• Writing *ptr = 35 opens box 0x7ffd2004 and changes its contents to 35.
• num now evaluates to 35 because both refer to the exact same memory cell!
3. Common Pointer Syntax Quick Reference
Expression Meaning / Action Type of Output
int *p; Declaration — creates a pointer variable designed to point to an int. Pointer definition
p = &x; Assigns the address of x to pointer p. Address assignment
p The memory address stored inside p. Memory address (hex)
*p Dereferencing: Accesses or modifies the value at address p. Integer value
&p The memory address where the pointer variable itself is located in RAM. Pointer's own address
⚠ Wild / Uninitialized Pointer Danger:
Declaring int *p; without setting an address makes it point to a random memory location! Writing *p = 50; can crash your operating system. Always initialize with NULL: int *p = NULL;!
💡 Two Uses of the Asterisk (*):
• In Declaration: int *p; → declares a pointer type.
• In Executable Code: *p = 20; → dereferences (fetches/updates value).
📝 One-Line Summary: & gives the memory address of a variable; a pointer stores that address; * accesses or updates the value at that address.
