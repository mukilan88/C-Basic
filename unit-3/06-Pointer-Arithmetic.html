🎯 Aim: To perform arithmetic operations on single values using dereferenced pointers (*p1 + *p2), understand pointer scaling rules, and traverse 1D arrays using pointer offsets *(ptr + i).
1. Arithmetic Operations on Single Values via Pointers

By applying dereferencing (*), pointers allow us to perform standard arithmetic (addition, subtraction, multiplication) directly on the values stored in separate memory locations:

#include <stdio.h>

int main() {
    int a, b, sum, diff, prod;
    int *p1 = &a, *p2 = &b;

    printf("Enter two numbers: ");
    scanf("%d %d", p1, p2); // p1=&a, p2=&b

    sum = *p1 + *p2; // Dereferencing to add values
    diff = *p1 - *p2; // Dereferencing to subtract
    prod = (*p1) * (*p2);

    printf("Sum = %d\n", sum);
    printf("Difference = %d\n", diff);
    printf("Product = %d\n", prod);
    return 0;
}
💻 Terminal Output (Arithmetic on Values):
Enter two numbers: 20 8
Sum = 28
Difference = 12
Product = 160
🔍 Dereferencing vs Address Operations
• *p1 + *p2: Extracts stored numbers (20 + 8 = 28).
• p1 + p2: Attempting to add addresses directly is illegal in C!
2. Pointer Scaling Rule & Address Jumps

When you add an integer to a pointer (ptr + 1), C scales the shift by the size of the target data type:
New Address = Current Address + (n × sizeof(data_type))

👁 Visualizing int *ptr = arr; → Each step jumps by +4 bytes:

If ptr = #2000, then ptr + 1 = #2004 (not #2001!), because sizeof(int) == 4.
3. Runtime Input & Array Traversal using Pointers
#include <stdio.h>

int main() {
    int arr[4], n = 4;
    int *ptr = arr; // Points to arr[0]

    printf("Enter 4 integers:\n");
    for (int i = 0; i < n; i++) {
        scanf("%d", (ptr + i)); // No & needed!
    }

    printf("\nValues and Addresses in RAM:\n");
    for (int i = 0; i < n; i++) {
        printf("At address %p: Value = %d\n",
               (void*)(ptr + i), *(ptr + i));
    }
    return 0;
}
💻 Terminal Output (Array Traversal):
Enter 4 integers:
10 20 30 40

Values and Addresses in RAM:
At address 0x7ffd2000: Value = 10
At address 0x7ffd2004: Value = 20
At address 0x7ffd2008: Value = 30
At address 0x7ffd200c: Value = 40
🔍 Array-Pointer Equivalence
In C, bracket notation is just pointer arithmetic:
• arr[i] is evaluated as *(arr + i)
• &arr[i] is identical to (arr + i)
4. Permitted vs. Illegal Pointer Operations
Operation Valid / Invalid? Formula / Example Behavior
Increment (ptr++) ✅ Valid Advances pointer forward by sizeof(type) bytes.
Decrement (ptr--) ✅ Valid Steps pointer backward by sizeof(type) bytes.
Adding Integer (ptr + n) ✅ Valid Moves pointer forward by n × sizeof(type) bytes.
Subtracting Pointers (p2 - p1) ✅ Valid Returns the number of elements between two pointers.
Adding Two Pointers (p1 + p2) ❌ ILLEGAL Adding two RAM addresses has no physical meaning!
Multiplication / Division ❌ ILLEGAL Operations like ptr * 2 or ptr / 3 cause compiler errors.
⚠ Parentheses Precedence Trap:
• *ptr++ → Reads value first, then increments pointer address.
• (*ptr)++ → Increments the actual integer data value at that address!
💡 Constant Array Pointer:
An array name is a constant pointer to its base index. You can run ptr++, but you cannot run arr++ because arr cannot change its base memory location!
📝 One-Line Summary: Dereference pointers (*p1 + *p2) to compute arithmetic on single values; pointer math (ptr + i) scales by data type size to traverse contiguous arrays.
