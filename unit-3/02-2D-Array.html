1. What is a 2D Array? & Tabular Layout

A 2D Array is an array of arrays organized in a grid of Rows and Columns (commonly called a Matrix).
Syntax: data_type array_name[rows][cols]; → e.g., int a[2][3]; reserves $2 \times 3 = 6$ integer elements ($6 \times 4\text{ bytes} = \mathbf{24\text{ bytes}}$).

• Index Formula: a[row_index][col_index]
• Row Index: Runs from 0 to rows - 1
• Col Index: Runs from 0 to cols - 1
• RAM Storage: Stored in contiguous Row-Major Order (Row 0 elements stored first, followed immediately by Row 1).
2. Runtime Input & Matrix Display (Complete Program)
#include <stdio.h>
int main() {
 int a[2][2], r, c;
 printf("Enter matrix elements (2x2):\n");
 // 1. Reading runtime values using Nested Loops
 for (r = 0; r < 2; r++) { // Outer loop: Rows
  for (c = 0; c < 2; c++) { // Inner loop: Columns
   scanf("%d", &a[r][c]);
  }
 }
 // 2. Printing in proper 2D Matrix Format
 printf("\nThe 2x2 Matrix is:\n");
 for (r = 0; r < 2; r++) {
  for (c = 0; c < 2; c++) {
   printf("%d\t", a[r][c]); // Tab space
  }
  printf("\n"); // Line break after each row
 }
 return 0;
}
💻 Terminal Execution (Runtime):

🔍 Why Nested Loops?
• Outer Loop (r): Selects the horizontal row.
• Inner Loop (c): Sweeps left-to-right through every column in that row.
• printf("\n");: Placed right after the inner loop finishes to start the next row on a fresh line!
3. Common 2D Array Operations
Operation Key Purpose Standard Loop Logic
1. Matrix Addition Adds matching elements from two identical-sized matrices ($C = A + B$) sum[i][j] = a[i][j] + b[i][j];
2. Matrix Transpose Swaps rows into columns ($B[j][i] = A[i][j]$) transpose[j][i] = a[i][j];
3. Diagonal Sum (Trace) Sums main diagonal elements where row index equals column index ($i == j$) if (i == j) { diag_sum += a[i][j]; }
4. Row-wise Sum Computes total sum of each individual row independently Reset row_sum = 0; before inner loop, print after.
⚠ Index Out-of-Bounds Trap:
In int a[2][3], the valid row indices are only 0, 1 and column indices are 0, 1, 2. Writing a[2][3] = 10; causes memory corruption!
💡 Matrix Initialization Trick:
You can initialize directly: int a[2][2] = {{1, 2}, {3, 4}};.
In C, you can omit the row dimension, but you must provide column dimension: int a[][2] = {1, 2, 3, 4};.
📝 One-Line Summary: A 2D array represents data in rows and columns; nested loops (outer for rows, inner for columns) are used to input, display, and process elements.
