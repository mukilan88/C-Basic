1. What is a File Pointer & Cursor Position?

A FILE *fp is a pointer to an internal C runtime control structure that tracks everything about an open file, including its buffer, mode, and crucially, its current byte offset position (the cursor).
Normally, reading or writing moves this cursor forward sequentially. But using C's random access functions, you can jump directly to any byte location!

2. The 3 Random Access Navigation Functions
🚀 1. fseek() – Move Cursor
Repositions file cursor to any byte offset.
fseek(fp, offset, origin);
Returns 0 on success.
📏 2. ftell() – Current Position
Returns current byte index from file start.
long pos = ftell(fp);
Helpful to compute total file size!
🔄 3. rewind() – Reset to Start
Snaps file cursor straight back to Byte 0.
rewind(fp);
Equivalent to fseek(fp, 0, SEEK_SET).
3. Complete Program: Random File Jumps & File Size
#include <stdio.h>

int main() {
    FILE *fp = fopen("letters.txt", "w+");
    char ch;

    // 1. Write initial text to file
    fputs("ABCDEFGH", fp);

    // 2. Jump to byte offset 3 (4th letter)
    fseek(fp, 3, SEEK_SET);
    printf("Position after seek: %ld\n", ftell(fp));
    ch = fgetc(fp);
    printf("Character read: %c\n", ch); // Reads 'D'

    // 3. Reset back to start with rewind()
    rewind(fp);
    ch = fgetc(fp);
    printf("Character after rewind: %c\n", ch); // 'A'

    // 4. Calculate total file size
    fseek(fp, 0, SEEK_END); // Move to end
    printf("Total File Size: %ld bytes\n", ftell(fp));

    fclose(fp);
    return 0;
}

🔍 The 3 Origin Constants for fseek()
• SEEK_SET (0): Offset measured from the start of the file.
• SEEK_CUR (1): Offset measured relative to current cursor location.
• SEEK_END (2): Offset measured from the very end of the file.
4. Quick Navigation Reference Table
Operation Task Code Instruction Cursor Shift Result
Rewind to Beginning rewind(fp);  or  fseek(fp, 0, SEEK_SET); Cursor placed at Byte 0 (first character)
Skip forward 5 bytes fseek(fp, 5, SEEK_CUR); Advances cursor forward by 5 positions
Step backward 3 bytes fseek(fp, -3, SEEK_CUR); Moves cursor back by 3 positions
Find total file size fseek(fp, 0, SEEK_END); long size = ftell(fp); Returns total byte count of the file
⚠ Negative Offset Trap:
Never pass a negative offset with SEEK_SET! Writing fseek(fp, -5, SEEK_SET) tries to access bytes before the beginning of the file, which produces undefined behavior and errors.
💡 Why Random Access Matters:
Imagine a database with 100,000 student records! Instead of looping through all 100,000 records, you can compute: fseek(fp, id * sizeof(struct Student), SEEK_SET); to fetch record #50,000 instantly!
📝 One-Line Summary: File pointers track the active byte cursor; navigate anywhere using fseek(), read your exact position with ftell(), and jump back to the start with rewind().
