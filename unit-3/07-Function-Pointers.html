PAGE 7: PREREQUISITE TO FUNCTION POINTERS – PARAMETER PASSING MECHANICS
🎯 Foundational Principle: Before studying Function Pointers, students must master parameter passing. In C, strictly speaking, there is only Call by Value. What is conventionally termed "Call by Reference" is practically implemented by passing variable addresses using pointers.
1. Side-by-Side Swapping Experiment
1. Call by Value (Passes Duplicate Copy)
Actual parameters are copied into separate formal parameter slots. Originals in caller scope remain unchanged.
#include <stdio.h>

void swap(int a, int b) {
    int temp;
    temp = a;
    a = b;
    b = temp;
}

int main() {
    int x = 10, y = 20;
    printf("Before swapping:\n");
    printf("x = %d, y = %d\n", x, y);
    swap(x, y);
    printf("After swapping:\n");
    printf("x = %d, y = %d\n", x, y);
    return 0;
}
Before swapping:
x = 10, y = 20
After swapping:
x = 10, y = 20  (Values remained unchanged!)
Why did swapping not happen?
When calling swap(x, y), values are cloned across functions:
main(): x = 10 -------------> swap(): a = 10
main(): y = 20 -------------> swap(): b = 20
Inside swap(): a = 20, b = 10. Only the copies exchange. The original variables remain x = 10, y = 20!
2. Call by Reference (Passes Memory Address)
Passing &x and &y allows the function to reach directly into the caller's memory via dereferencing.
#include <stdio.h>

void swap(int *a, int *b) {
    int temp;
    temp = *a;
    *a = *b;
    *b = temp;
}

int main() {
    int x = 10, y = 20;
    printf("Before swapping:\n");
    printf("x = %d, y = %d\n", x, y);
    swap(&x, &y);
    printf("After swapping:\n");
    printf("x = %d, y = %d\n", x, y);
    return 0;
}
Before swapping:
x = 10, y = 20
After swapping:
x = 20, y = 10  (Swapping succeeded!)
How does it work step-by-step?
&x and &y pass RAM addresses into pointers a and b.
• *a means: Go to address in a → accesses x.
• Step 1: temp = *a; → temp = 10
• Step 2: *a = *b; → x = 20 (updates original x)
• Step 3: *b = temp; → y = 10 (updates original y)
2. Comprehensive Comparison Table & Memory Rules
Feature Call by Value Call by Reference (Using Pointers)
What is passed? Value (duplicate data copy) Address of the variable in RAM
Uses pointer? No Yes (int *a, int *b)
Original variable modified? No (caller variables remain untouched) Yes (direct mutation in memory)
Function parameter type Normal variable: int a Pointer variable: int *a
Function call syntax swap(x, y); swap(&x, &y);
Accessing value inside body Direct evaluation: a Dereference operator: *a
Easy-to-Remember Mantra Value → Copy → No change in original Address → Pointer → Original can be changed
3. Important Symbols & Transition to Function Pointers

&x Unique memory address where variable x resides
int *p Declares p as a pointer variable pointing to an integer
*p Dereferencing: Fetches value at address held in p

🔑 Connection to Function Pointers (Avoid this Confusion):
• Pointer to a Variable (int *p;): Stores the address of a data variable in RAM.
• Pointer to a Function (int (*fp)(int, int);): Stores the address of an executable function in the Code Segment.
Example: int (*fp)(int, int) = add; allows running printf("%d", fp(10, 20)); to output 30!
4. The Full Learning Pathway
1. Functions → 2. Arguments & Params → 3. Call by Value → 4. Pointers → 5. Call by Reference → 6. Function Pointers → 7. Callbacks
📝 One-Line Summary for Students: Call by Value passes a copy of the value, whereas Call by Reference passes the address of the variable using pointers, allowing the function to modify the original variable.
